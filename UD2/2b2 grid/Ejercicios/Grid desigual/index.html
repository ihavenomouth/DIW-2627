Rejilla desigual

El truco consiste en tener tres columnas en lugar de dos, haciendo que se solapen en el centro las dos divisiones que están en cada fila.

Cada división tendrá una propiedad CSS clip-path diferente.

Con clip-path: polygon( punto, punto, punto, punto,...) podemos definir un polígono que definirá la parte de la división que se verá. Cada punto será un par de coordenadas x y. Por ejemplo, la primera imagen tiene la siguiente propiedad.

clip-path: polygon(0% 0%, 95% 0, 85% 100%, 0% 100%);
