Pseudoelementos

Los pseudoelementos permiten añadir contenido que no existe en el HTML por motivos estéticos. Algunos de estos pseudoelementos los hemos trabajado aunque sin prestarles demasiada atención, como por ejemplo ::placeholder o ::marker.

Al igual que las Pseudo-classes, los pseudo-elementos se añaden a los selectores, pero no describen un estado especial sino que, permiten añadir estilos a una parte concreta del elemento.

Texto seleccionado

Si intentas seleccionar el texto de una web ¿qué colores se utilizan? ¿quién los ha decidido?

En esta web se usa profusamente crimson como color principal y el yellow como color de acento de algunas partes muy concretas como la URL del <blockquote>. ¿Por qué no usar precisamente esos colores para resaltar el texto seleccionado?


  *::selection {
    color: crimson;
    background-color: #ffee00;
  }

Listas

En las listas, se puede elegir el tipo de lista con la propiedad list-type del elemento <ul> (la viñeta elegida será común a todos los ítems) o del elemento <li>.

Una poder personalizar la viñeta es usando el pseudoelemento li::marker.

Inputs

Los inputs tienen un pseudoelemento ::placeholder que recoge el valor del atributo html placeholder. Ese psudoelemento podemos estilarlo para que adapte a nuestras necesidades estéticas.

Primera línea y primera letra

Puede ocurrir que queremos destacar a de alguna manera la primera línea de un párrafo, pero no podemos estar seguros de cuándo termina esa primera línea porque depende del ancho del contenedor en el que se encuentre y también del tamaño del texto. También puede ocurrir que nos interese destacar la primera palabra del párrafo por razones estilísticas. Esto último es algo relativamente común en algunas novelas.
