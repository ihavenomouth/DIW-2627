    Explicación

    Conceptos básicos

    Flex permite organizar los elementos siguiendo un eje principal. Ese eje principal se establece mediante el atributo flex-direction.

    Flex siempre va a intentar colocar los elementos en el eje principal sin tener que hacerlos más pequeños. Es parecido a lo que conseguimos con la propiedad width: máx-content.

    Si todos los elementos caben en el eje principal, se puede establecer cómo se va a distribuir el espacio sobrante en el eje principal con justify-content.

    Si los elementos no caben, el navegador tendrá que hacer los elementos más pequeños. Si aún así no caben, se producirá un overflow o desbordamiento.

    Asigna a <header> el siguiente estilo:

          display: flex;
      flex-direction: column;
      justify-content: space-between;

    Juega con los valores de flex-direction y justify-content.

    Repite la operación con <menu>, asignando los valores que corresponden para que efectivamente sea un menú:

          display:flex;
      justify-content: center;
      gap: 1rem;

    Fíjate que con la propiedad gap podemos separar los elementos con flex y olvidarnos de los margin y problemas de margin-collapse.

    Podemos separar los elementos del menú usando margin-left:auto en alguno de los <li>, pero en ese caso ya no se tendrá en cuenta el valor de justify-content.

    Para distribuir el espacio en el eje secundario podemos utilizar la propiedad align-items. Puedes probarlo en el elemento <menu>. Las opciones disponibles son parecidas a las de justify-content, aunque más limitadas siendo la más utilizada center.

    Precisamente usando justify-content: center y align-items: center conseguimos centrar un elemento vertical y horizontalmente.

    Flex-grow, flex-shrink y flex-basis

    Hemos dicho que flex intentará reducir el tamaño de los elementos a su contenido si hay suficiente espacio. Añade unas cuantas opciones más al menú y verás que las más largas necesitarán dos líneas para que quepa todo el texto.

    Si sigues añadiendo elementos, verás que se terminará produciendo un desbordamiento. Para evitarlo se puede usar flex-wrap: wrap que permitirá tener más de una fila de elementos en el eje principal. Esto desbloquea otras propiedades avanzadas de flex.

    Quitemos las opciones extra que hemos añadido al menú. Cuando el espacio disponible se reduce horizontalmente (por reducir la pantalla del navegador, por ejemplo), se reduce también el espacio que cada <li> ocupa.

    Esto es posible porque cada elemento hijo de un flex tiene las siguientes propiedades por defecto:

          flex-grow: 0;
      flex-shrink: 1;
      flex-basis: auto;

    Es decir, no puede crecer (por eso queda espacio vacío que gestionar), pero sí puede reducir el tamaño que ocupa.

    Haz la prueba asignando al mayor <li> la propiedad flex-shrink:0 y verás que es el único que no reduce su tamaño.

    Si ahora asignas a todos la propiedad flex-grow:1 verás que todos crecen hasta ocupar el espacio disponible. Para calcular cuánto crecen o decrecen, lo que hace el navegador es asignarles por defecto a todos un tamaño de 0px e ir aumentando su tamaño hasta conseguir que quepa todo su contenido. El resto del espacio disponible se distribuye proporcionalmente a su tamaño.

    Precisamente para indicar manualmente el tamaño por defecto se usa la propiedad flex-basis (puedes considerarla similar al width). Puedes hacer la prueba asignando al último elemento de la lista el mismo valor para flex-basis que el ancho del elemento más grande.

    Si ahora cambias el espacio disponible para que sea más pequeño, verás que su tamaño se reduce al mismo nivel que el del elemento más grande. Si cambias que todos puedan crecer (flex-grow:1) verás que crece tanto como aquel.

    Cambiar la propiedad flex-grow a 1 no modificará nada por sí sola, porque todo el espacio disponible ya ha sido asignado.

    Hay varias maneras de conseguir el efecto deseado. La opción correcta es asignar el mismo valor de flex-basis a las tarjetas, un valor muy grande, de manera que como pueden por defecto encogerse, lo harán en la misma proporción.

    flex-basis: 100%; /* el ancho del contenedor */
flex-shrink: 1; /* opción por defecto */

    Nota: no uses números mágicos como 33%, que funcionará justo en este ejemplo con 3 columnas, pero no si tenemos 2 columnas (no se ocupará todo el espacio horizontal).

    Otra opción sería justo la contraria, asignar un valor muy pequeño y permitirles que crezcan. Lo harán proporcionalmente al tamaño. Mira la opción flex:1 que se explica más adelante.

    flex-basis: 50px;
flex-grow: 1;

    Para conseguir el mismo efecto se suele usar la propieda flex:1. La propiedad flex:1 es una abreviatura de las tres propiedades que ya hemos visto con estos valores concretos (que ya debes saber por qué funciona):

    flex-grow: 1;
flex-shrink: 1;
flex-basis: 0;

    Importante: En este ejemplo funciona correctamente porque tienen el mismo borde y padding. Cambia el padding de la primera división a padding: 2rem; y verás que la última división es más ancha. Esto ocurre porque cuando se calcula el espacio que se le va a asignar, se parte de un tamaño de 0 y se va aumentando poco a poco el tamaño, sin tener en cuenta bordes ni padding, hasta tener el box-content. Tiene sentido porque de la otra manera el padding podría varíar en función del espacio disponible, estropeando el diseño.

    Nota: este es un ejemplo en el que es mejor usar grid y ahorrarnos estos problemas.

    display: grid;
gap: 2rem;
grid-template-columns: 1fr 1fr 1fr;

    Otras consideraciones, order, align-self y align-content

    Podemos cambiar el orden visual de algún elemento en flex usando la propiedad order. Prueba en el menú de navegación a aplicar a algunos elementos diversos valores como order: -1, order:1. Cuanto menor sea el número, antes aparecerá.

    Se puede cambiar el ajuste concreto en el eje secundario para un elemento concreto usando la propiedad align-self.

    Por último, cuando un elemento flex tiene activado el flex-wrap: wrap y además sus hijos se expanden hasta necesitar más de una fila (o columna, dependiendo del eje principal usado), podemos utilizar align-content con las mismas opciones que el justify-content (es decir, space-around, space-between, etc).
