01. Fundamentos

El Modelo de Cajas y los Ejes de Flexbox

Al aplicar display: flex a un elemento padre, este se convierte en un Flex Container y sus hijos directos pasan a ser Flex Items. La clave de Flexbox radica en sus dos ejes:

Eje Principal (Main Axis) ➔
Eje Cruzado (Cross Axis) ➔
1
2
3

🎯 Eje Principal (Main Axis)

Es la dirección en la que fluyen los elementos. Se controla con justify-content. En row va de izquierda a derecha; en column va de arriba a abajo.

📐 Eje Cruzado (Cross Axis)

Es el eje perpendicular al principal. Se controla con align-items y align-content. Permite alinear los elementos transversalmente.

02. Propiedades del Padre

Propiedades del Contenedor (Flex Container)

Estas propiedades se aplican al elemento que tiene display: flex y afectan a cómo se organizan todos sus hijos.

flex-direction

06. Referencia Rápida

Chuleta Completa de CSS Flexbox

Guarda esta tabla para consultarla rápidamente en tus proyectos.

Propiedad Se aplica a Valores principales Descripción y uso clave
display Contenedor flex | inline-flex Habilita el contexto flex para todos los hijos directos.
flex-direction Contenedor row | row-reverse | column | column-reverse Establece el eje principal y la orientación del flujo.
justify-content Contenedor flex-start | center | flex-end | space-between | space-around | space-evenly Distribuye los elementos y el espacio libre a lo largo del eje principal.
align-items Contenedor stretch | flex-start | center | flex-end | baseline Alinea los elementos a lo largo del eje perpendicular (cruzado).
flex-wrap Contenedor nowrap | wrap | wrap-reverse Permite o prohíbe que los elementos salten de línea cuando no caben.
align-content Contenedor stretch | flex-start | center | flex-end | space-between | space-around Alinea las líneas completas entre sí (solo funciona si flex-wrap: wrap tiene más de 1 fila).
gap Contenedor <longitud> (ej: 16px, 1rem) Establece el espacio entre elementos (atajo para row-gap y column-gap).
flex-grow Elemento Hijo <número> (ej: 0, 1, 2) Define la proporción de espacio sobrante que absorbe este ítem relativo a los demás.
flex-shrink Elemento Hijo <número> (ej: 1, 0) Define la capacidad de encogerse si no hay espacio suficiente (0 = no se encoge).
flex-basis Elemento Hijo auto | <longitud> (ej: 200px) Tamaño por defecto antes de que se aplique flex-grow o flex-shrink.
flex Elemento Hijo flex: 1 | flex: 0 1 auto Atajo estándar para flex-grow flex-shrink flex-basis.
align-self Elemento Hijo auto | flex-start | center | flex-end | stretch | baseline Sobrescribe la alineación align-items para un solo elemento específico.
order Elemento Hijo <entero> (ej: -1, 0, 1) Cambia el orden visual sin alterar la estructura del código HTML.
