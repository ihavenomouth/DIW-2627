Modelo de cajas de CSS

Imagina que queremos crear un diseño en el que aparezcan cuadrados de exactamente 100px de ancho. Lo más sencillo es realizar lo siguiente:

    section div{
      width: 100px;
      height: 100px;
    }

Ahora añadimos un padding y un borde para mejorar la estética.

    section div{
      width: 100px;
      height: 100px;
      border: 5px dashed #123;
      padding: 10px;
    }

Cada cuadro tiene un lado de 100px de ancho e incluye un borde de 5px y un padding de 10px. Sumando estos valores tendremos por tanto: 5+10+100+10+5 + 5+10+100+10+5 + 5+10+100+10+5 = 390 píxeles.

Si bien en principio esto puede parecer razonable, en la práctica causa muchos problemas. El borde y el padding ocupan espacio y, como se ve en el ejemplo de abajo, se extiende el fondo.

Si queremos que ocupen 100px, en realidad el ancho debería ser menor, de sólo 70px.

Esto obliga a tener en cuenta el tamaño del borde y el padding al crear el layout de nuestro diseño para evitar posibles desbordamientos.

Para evitar tener que estar realizando sumas, lo más sencillo es utilizar la regla *,::before,::after{box-sizing: border-box}, de manera que el borde en lugar de extender la caja hacia afuera, se colocará por dentro. Pulsa F12 y modifica la regla CSS para ver la diferencia. Podrás ver que ahora las cajas ocuparán 300px independientemente del padding o el borde.
