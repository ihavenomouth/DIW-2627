Selectores especiales en CSS

Selector +

El primero de los selectores especiales que vamos a ver es el selector +, que permite seleccionar los hermanos inmediatos de otro selector. Lo importante es que los elementos seleccionados deben aparecer inmediatamente detrás del primer selector.

Un ejemplo muy típico a la hora de hacer un documento de texto es que al primer párrafo no se le suele aplicar una sangría de primera línea, mientras que a los siguientes sí. De esta manera el primer párrafo tendrá todas sus líneas rectas, mientras que los siguientes tendrán una sangría de primera línea.

En este mismo texto se puede apreciar la ausencia de sangría en el primer párrafo y su presencia en los siguientes. El CSS que se está aplicando a los párrafos es el siguiente.

p{
  text-align: justify;
}

p + p{
  text-indent: 1rem;
}

Sin embargo, en este párrafo no se aplica la sangría de primera línea, porque aunque es un hermano de otros párrafos, su hermano inmediatamente anterior es un elemento pre.

Otro ejemplo es el de un campo de formulario en el que el mensaje de error ya está presente en el HTML, pero no está visible.

En el formulario de abajo ocurre precisamente esto, si escribes un nombre que no cumpla las restricciones, aparecerá el mensaje de error.

El CSS del mensaje de error es sencillo, sólo vamos a destacar un par de reglas relacionadas con él porque el resto no es relevante (puedes verla con las Developer tools si te interesa).

El mensaje de error ya aparece en el HTML, pero tiene asignada la regla display: none;, de modo que está oculto.

Cuando el contenido del input cambia y resulta ser erróneo, se le aplica la pseudoclase :invalid y por tanto la segunda regla entra en juego. Esto es posible porque el mensaje de error es hermano directo del cuadro de texto.

        p.mensaje-error{
          display: none;
          ...
        }

        input:invalid + p.mensaje-error{
          display: block;
        }

Selector ~

El segundo selector especial es ~ (en castellano ese símbolo se conoce como virgulilla), que permite seleccionar los hermanos del primer selector sean o no hermanos directos. Es decir, se seleccionarán aunque haya otras etiquetas entre ellos.

Por ejemplo, el encabezado <h2> de esta sección tiene una clase llamada virgulilla.

Si ahora vamos al CSS, veremos que existe la siguiente regla.

.virgulilla ~ pre{
  border: 2px dotted #7c5e10;
}

Como se ve se el recuadro de arriba tiene un borde puntuado por esa regla, porque se seleccionan los <pre> que son hermanos de una etiqueta con la clase virgulilla.

Sin embargo el pre de abajo no se ve afectado porque no es un hermano del <h2> al encontrarse dentro de un <div>

Este recuadro no se ve afectado porque es el hijo de un hermano (un sobrino), no un hermano directo.

Otro ejemplo es el de un menú que aparece cuando se pulsa un botón. En este caso en lugar de un botón se ha usado un checkbox que se ha ocultado, se marcará y desmarcará pulsando en la etiqueta (que se ha estilizado como si fuera un botón).
