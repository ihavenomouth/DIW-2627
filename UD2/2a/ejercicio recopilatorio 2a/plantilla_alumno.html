Tema 2a: CSS · Ejercicio Recopilatorio

Tarjeta Informativa "DevPress"

Tiempo estimado: 60 minutos  |  Puntuación: 10 puntos  |  Fichero de entrega: estilos.css

Objetivo: Diseña una hoja de estilos externa vinculada al HTML base semántico. Deberás estructurar la página en flujo normal (sin float, flex ni grid) usando únicamente 4 colores definidos en variables de :root.

Requisitos del Ejercicio

1. Paleta de 4 Colores y Reset Global (2.0 pts)

Declara en :root exactamente cuatro variables de color: el color primario, un fondo suave, un color para tarjetas y uno para textos. Toda la página debe usar exclusivamente estos 4 colores mediante var(...). Aplica el reseteo *, ::before, ::after { box-sizing: border-box; }. En body aplica color de fondo y tipografía. Centra la tarjeta main.tarjeta con margin: 2rem auto; y un ancho máximo de 60ch con padding: 2rem;.

2. Tipografía, Bordes y Combinador de Hermanos (2.0 pts)

Añade un borde visible y esquinas redondeadas (border-radius) a la tarjeta. Aplica text-wrap: pretty a los párrafos. Utiliza el combinador de hermano adyacente (p + p) para que los párrafos sucesivos tengan un margen superior adicional de 1rem. Fuerza la herencia del tipo de letra en los controles con button, input { font: inherit; }.

3. Lista de Novedades con Selectores Estructurales (2.0 pts)

Quita las viñetas por defecto a ul.novedades. Con el combinador de hijo directo (ul.novedades > li), añade relleno y margen a cada ítem. Alterna el color de fondo de las filas utilizando li:nth-child(even) y li:nth-child(odd) usando dos de tus cuatro colores. Al colocar el cursor encima (li:hover), resalta el elemento cambiando su color de fondo.

4. Formulario y Validación Visual sin Desplazamientos (2.0 pts)

El campo de correo es obligatorio. Cuando sea válido (:valid) y cuando sea inválido (:invalid), refleja su estado cambiando el color de fondo o borde (usando tus variables). Al recibir el foco (:focus), destaca el campo con outline para no alterar el tamaño de la caja. El botón tendrá display: block; width: 100%; padding: 0.8rem; y estilos diferenciados para :hover y :active.

5. Interactividad con :target y :has() (2.0 pts)

El bloque aside#aviso estará oculto al cargar la página con display: none;. Al pulsar el enlace que apunta a su ID, muéstralo mediante #aviso:target { display: block; }. El enlace de cerrar apunta a #. Además, añade automáticamente un asterisco del color primario tras la etiqueta del campo obligatorio usando label:has(input:required)::after.

Estructura HTML Base (index.html)

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>DevPress - Novedades</title>
  <link rel="stylesheet" href="estilos.css">
</head>
<body>

  <main class="tarjeta">
    <header>
      <h1>Boletín Semanal DevPress</h1>
      <p>Las mejores novedades y trucos de CSS directamente en tu correo.</p>
    </header>

    <section class="novedades-bloque">
      <ul class="novedades">
        <li>Nuevas pseudoclases en los navegadores actuales</li>
        <li>Cómo optimizar la especificidad en hojas extensas</li>
        <li>Buenas prácticas de box-sizing: border-box</li>
      </ul>
      <p><a href="#aviso">Ver condiciones de la suscripción</a></p>
    </section>

    <aside id="aviso" class="caja-aviso">
      <p>Condiciones: Sin spam. Puedes cancelar tu suscripción cuando quieras.</p>
      <a href="#">Cerrar aviso</a>
    </aside>

    <section class="registro-bloque">
      <form action="#" method="post">
        <label for="txtCorreo">Introduce tu correo:</label>
        <input type="email" id="txtCorreo" name="txtCorreo" required placeholder="tu@correo.com">
        <button type="submit">Suscribirme al boletín</button>
      </form>
    </section>
  </main>

</body>
</html>

Recuerda: Todo el diseño se resuelve con flujo normal (sin float, flex ni grid) y usando exclusivamente las cuatro variables de color definidas.
